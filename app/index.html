      Keep the ink inside a PDF file?

      • OverBoard saves a PDF on this computer with all class periods' ink stored inside it.
      • Your pages are not changed. The ink is added at the end of the file. Preview, Acrobat and Chrome show the plain PDF.
      • Open that file in OverBoard on any computer and the ink comes back, ready to keep writing.
      • While this is on, every change is saved into that file a few seconds after you stop writing. Tap the same button to turn it off.
      • We suggest a new file, Name_board.pdf. If you choose the original PDF instead, OverBoard adds the ink to the original.
      • This browser can't keep saving into a file, so you get a one-time download, Name_board.pdf. Chrome or Edge can keep it saved automatically.

      Leave it off and nothing changes: ink still saves in this browser.
